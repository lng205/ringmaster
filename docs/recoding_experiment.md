# 重编码增益实验

## 目标

验证多跳场景下，Relay 重编码等效于 Sender 增加多少冗余。

## 实验配置

### 网络拓扑

```
Sender ──hop1──> Relay ──hop2──> Receiver
```

### 对照组

| 组 | Sender R | Relay R | 说明 |
|----|----------|---------|------|
| 透传 R=0.1 | 0.1 | 0 | 基线 |
| 透传 R=0.2 | 0.2 | 0 | |
| 透传 R=0.3 | 0.3 | 0 | |
| 透传 R=0.4 | 0.4 | 0 | |
| 重编码 | 0.1 | 0.1 | Relay 重编码 |

### 网络参数

- 每跳: loss% + 25ms
- 丢包率: 0%, 5%, 10%, 15%, 20%

### 视频参数

1920×1080, 24fps, 2Mbps

### 时长

- 丢包 0%~10%: 10秒
- 丢包 15%~20%: 30秒
- 重复: 3次

## 运行

```bash
./run_recoding_exp.sh
```

## 指标

- **帧可解码率**: 成功解码帧数 / 预期帧数

## 分析

比较"重编码"曲线与各"透传"曲线，确定 Relay R=0.1 等效于 Sender 多加多少冗余。
